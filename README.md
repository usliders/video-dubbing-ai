# video_dubbing_ai_2025

## Описание
Платформа для автоматического дубляжа видео с поддержкой zero-shot и few-shot voice cloning, автоматическим ASR, переводом, TTS и анализом качества (similarity).

## Структура каталогов

- data/input/ — исходные видео (input.mp4) и reference-голоса (reference_audio1.wav, ...)
- data/output/ — итоговые видео (с датой/временем в имени)
- data/temp/ — временные файлы (уникальные для каждого запуска, не затираются)
- notebooks/ — ноутбуки с автоматизированными экспериментами
- src/ — исходный код (модули vision_audio, asr, mt, tts, eval и др.)

## Автоматизация экспериментов
- Все этапы (извлечение аудио, VAD, ASR, перевод, TTS, сравнение similarity, визуализация) автоматизированы в ноутбуке `notebooks/experiments_automated.ipynb`.
- Для reference-фрагментов автоматически проводится VAD и отбор только коротких чистых сегментов (5–10 сек).
- Для каждого reference-фрагмента автоматически выполняется ASR для получения текста.
- Временные файлы для каждого запуска создаются в отдельной уникальной папке внутри data/temp.
- Итоговые видео сохраняются в data/output или temp_run_dir с уникальным именем (дата/время).
- Все пути универсальны и работают как из ноутбука, так и из main.py.
- Пайплайн устойчив к ошибкам: fallback на extracted_audio.wav, обработка NaN, несовместимость версий и др. снабжены информативными сообщениями.

## Сценарии экспериментов
1. Zero-shot: дубляж с голосом оригинального спикера (используется только один короткий чистый сегмент 5-10 сек, без пауз и шумов; reference выбирается автоматически: сначала zero_shot_reference.wav, затем run_extracted_audio.wav, затем любой reference_audio*.wav)
2. Few-shot: fine-tuning (дообучение) TTS-модели на нескольких коротких записях нового голоса (используются только 3 коротких reference_audio*.wav, найденные в папке input), с сохранением чекпоинта и генерацией итогового видео этим чекпоинтом

## Подготовка данных
- Для zero-shot: положите короткий чистый сегмент речи в data/input/zero_shot_reference.wav (если его нет, будет использовано оригинальное аудио из видео или первый reference_audio*.wav)
- Для few-shot: положите несколько файлов reference_audio*.wav в data/input/ (дообучение будет проведено только на первых 3 найденных файлах)
- Тексты для дообучения будут автоматически получены через ASR для каждого reference-фрагмента

## Этапы пайплайна
- Извлечение аудио из видео
- Сегментация аудио с помощью VAD (Voice Activity Detection, pyannote.audio)
- ASR (распознавание речи)
- MT (машинный перевод)
- TTS (zero-shot или few-shot, с дообучением)
- Сборка итогового видео
- Анализ similarity и автоматическая визуализация результатов

## Анализ similarity
- Для оценки качества клонирования добавлен расчёт upper bound: сравниваются несколько оригинальных сегментов спикера между собой (см. src/eval/similarity.py)
- Это значение можно использовать как ориентир для максимального similarity, достижимого на реальных данных
- Визуализация включает таблицы, line plot, boxplot, pie chart

## Как использовать
- Поместите input.mp4 и reference_audioX.wav в data/input/
- Для zero-shot reference выбирается автоматически (см. выше)
- Для few-shot дообучение проводится только на первых 3 reference_audio*.wav
- Если не найден ни один reference — будет информативная ошибка
- Запустите основной пайплайн:
  ```
  python main.py
  ```
- Или откройте и выполните ноутбук:
  ```
  jupyter notebook notebooks/experiments_automated.ipynb
  ```
- Для запуска в Docker используйте инструкции из DOCKER_INSTRUCTIONS_RU.md

## Рекомендации
- Для повышения качества дубляжа используйте 3–5 разнообразных коротких reference-фрагментов
- Контролируйте качество сегментов (VAD, отсутствие шума)
- При необходимости расширяйте пайплайн (например, автоматическая фильтрация по quality, новые TTS/ASR/MT модели)
