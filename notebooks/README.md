# notebooks/

Здесь находятся экспериментальные ноутбуки для анализа и тестирования пайплайна дубляжа.

## Основной ноутбук
- **experiments_automated.ipynb** — полностью автоматизированный пайплайн для дубляжа видео с поддержкой zero/few-shot клонирования голоса, автоматическим VAD, ASR, MT, TTS, анализом similarity и визуализацией результатов.
- Все этапы — от подготовки reference до анализа качества — реализованы в одном ноутбуке.
- Для каждого запуска создаётся уникальная временная папка, все промежуточные и итоговые данные сохраняются автоматически.

## Как запускать
- Рекомендуется запускать именно этот ноутбук для полного анализа:
  ```
  jupyter notebook experiments_automated.ipynb
  ```
- Все параметры и структура данных описаны внутри ноутбука.
